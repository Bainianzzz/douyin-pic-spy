# Douyin Pic Spy · 抖音图文视频下载器

[English](docs/README.en.md) · 中文

一个 Tampermonkey 油猴脚本：在抖音网页版打开**图文视频**，一键把该作品的全部图片下载到你指定的文件夹，**每个作品自动打包成一个子文件夹**。

---

## 特性

- **一键下载**：作品页右下角按钮，点一下即可，不遮挡视频。
- **自选保存位置**：基于 File System Access API，选择一次目标文件夹后长期记住。
- **按作品分文件夹**：`目标目录/标题_时间戳/01.jpg`、`02.jpg` …… 结构清晰。
- **抓取原图**：优先从抖音接口拿到原图地址，画质高于页面缩略图。
- **命名可切换**：`标题_时间（默认）` / `标题_ID` / `仅标题` / `仅ID`。
- **自动更新**：脚本头内置 `@updateURL`，随仓库更新。

## 安装

### 1. 安装脚本管理器

- [Tampermonkey 篡改猴](https://www.tampermonkey.net/)（推荐）
- 或 Violentmonkey / ScriptCat

### 2. 安装脚本

点击下面任一方式：

- **直接安装**：[`douyin-pic-spy.user.js`](https://raw.githubusercontent.com/Bainianzzz/douyin-pic-spy/main/douyin-pic-spy.user.js)（点击后脚本管理器会弹出安装页）
- **手动**：下载 `douyin-pic-spy.user.js`，拖进浏览器窗口 → 点击「安装」

> 需要浏览器为 **Chrome / Edge**（原因见「兼容性」）。

## 使用

1. 打开抖音网页版，进入任意**图文视频**页（`www.douyin.com/note/<id>` 或视频详情页）。
2. 右下角出现胶囊按钮 `⬇ 下载图片 ｜ ⚙`。
3. 首次使用点击 **⚙** 打开设置 → **选择文件夹**，授权目标目录（只需一次）。
4. 点击 **⬇ 下载图片**。按钮上方出现进度气泡，完成后提示 `完成：成功 N → 目录/子文件夹`。
5. 到目标目录查看：`你的目录/作品标题_20261009_161430/01.jpg` …

### 批量下载

在「我的主页」的以下标签页，按钮会变成 **批量下载**：

| 标签页 | 地址 |
| --- | --- |
| 推荐 | `douyin.com/user/self?showTab=recommend` |
| 喜欢 | `douyin.com/user/self?showSubTab=video&showTab=like` |
| 收藏 | `douyin.com/user/self?showSubTab=video&showTab=favorite_collection` |
| 观看历史 | `douyin.com/user/self?showSubTab=video&showTab=record` |
| 稍后再看 | `douyin.com/user/self?showSubTab=video&showTab=watch_later` |

用法：

1. 滚动页面，让列表加载出要下载的作品。只有滚到过的作品才会被截获，没滚到的不能选。
2. 点 **批量下载** 进入选择态，点封面选择作品。
3. 灰掉的是纯视频（无法下载）或未截获的作品，不可选。
4. 底部点 **开始下载**，作品按顺序串行下载，每个作品一个子文件夹；结束时汇总成功、未截获、失败的数量，并列出未截获的标题。
5. 点 **退出选择** 或底部 **取消** 退出选择态。

注意：部分图文可能提取失败，需要手动下载。

### 设置项

| 选项 | 说明 |
| --- | --- |
| 命名方式 | 子文件夹命名规则，默认 `标题_时间（默认）` |
| 目标位置 | 选择并记住保存目录，按钮上显示当前目录名 |
| 重下前清空该作品文件夹 | 同名文件夹重下前先清空，避免残留旧图；`标题_时间` 模式下自动置灰（每次生成新文件夹） |

设置**即时生效**，改完直接点「下载图片」即可，无需刷新页面。
